Seittikuvio · Cobweb Plot

FI

Seittikuvio on Näyte 007:n vastine mikroskoopin alla: se näyttää yhden r:n arvon iteroinnin askel askeleelta. Pystyviiva nostaa nykyisen arvon käyrälle, vaakaviiva heijastaa sen takaisin y=x-suoralle — toistuen.

EN

The cobweb plot is Specimen 007 under a microscope: it shows one value of r iterated step by step. A vertical line lifts the current value onto the curve, a horizontal line reflects it back onto the y=x line — repeating.

Havainto · Observation

Pienellä r:llä seitti kiertyy sisään yhteen pisteeseen. Suuremmalla se hyppii kahden, sitten neljän pisteen välillä — täsmälleen samat siirtymät, jotka näkyvät Näyte 007:n haarautumisina.

At small r, the web spirals into a single point. At larger r, it hops between two points, then four — exactly the same transitions that show up as branchings in Specimen 007.
